# Security

`human-approval-gate` is a small library with no dependencies. Please read "What it is not" in the README: the gate records decisions, it does not authenticate people and it does not sandbox the handlers you write.

If you find a security problem in the code, or something sensitive committed by mistake (a credential, personal data), please report it **privately** with GitHub's *Report a vulnerability* button on the **Security** tab, rather than in a public issue.
